# 제주 관광 AI 실습

제주 관광 데이터를 활용해 AI 실습을 진행하는 저장소입니다.

## 폴더 구조

```
.
├── data/      # 실습 데이터
├── outputs/   # 결과물
├── prompts/   # 내 프롬프트 기록
└── README.md
```

## 폴더별 안내

### 📂 `data/` — 실습 데이터
AI 실습에 사용하는 원본 데이터를 넣습니다.
- 제주 관광지, 맛집, 숙소 목록 (CSV, Excel)
- 방문객 통계, 리뷰 데이터
- 공공데이터포털 등에서 내려받은 자료
- 원본 파일은 수정하지 말고, 가공한 파일은 이름에 `_정제` 등을 붙여 구분합니다.

### 📂 `outputs/` — 결과물
AI로 만든 결과물을 저장합니다.
- 여행 일정표, 관광지 추천 목록
- 분석 결과 표, 차트 이미지
- 요약 보고서, 홍보 문구
- 파일 이름에 날짜를 붙이면 관리하기 쉽습니다. (예: `2026-11-03_3박4일_일정.md`)

### 📂 `prompts/` — 내 프롬프트 기록
AI에게 입력한 프롬프트와 그 결과에 대한 메모를 기록합니다.
- 사용한 프롬프트 원문
- 잘 된 점 / 아쉬운 점, 개선한 버전
- 어떤 데이터(`data/`)를 쓰고 어떤 결과(`outputs/`)가 나왔는지 함께 적어 두면 좋습니다.
