# 근거 자료: 네이버 AI 브리핑

## AI 브리핑
검색 결과 맨 위에서 여러 글을 요약하고 출처를 붙여 주는 네이버 서비스.
네이버는 검색 결과에 잘 노출되는 양질의 글이 인용될 가능성이 높다고 밝혔다.

## 기본 원칙 5가지 (네이버 검색, 2026-05-26)
1. 직접 경험한 지식
2. 일관된 주제
3. 거짓 없는 진정성
4. 읽기 쉬운 구조
5. 최신성 유지

## 셀프 점검표 5가지 (네이버 검색, 2026-06-04)
1. 독자와 목적
2. 절차와 해결 과정
3. 대안 비교
4. 실제 결과
5. 맥락에 맞는 사진·영상

## 실전 요령
- 제목: `검색어 + 누구`
- 본문: 순서 · 비교 · 결과
- 사진: 내가 직접 찍은 사진 3장부터

## 네이버 메이트 (2026년 6~12월 베타)
- AI 브리핑 인용수를 중심으로 매월 선정
- 선정 월에 활동 지원금 30만 원 지급
- 선정·지원 조건은 바뀔 수 있으니 안내할 때는 네이버 공지를 확인하라고 덧붙인다.
