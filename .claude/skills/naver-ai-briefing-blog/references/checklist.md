# 셀프 점검표 (초안 아래에 붙인다)

| 점검 항목 | 확인할 것 | 결과 | 보완할 점 |
|---|---|---|---|
| 독자와 목적 | 첫 문단에 누구를 위한 글인지, 무엇을 알려 주는지 나오나 | | |
| 절차와 해결 과정 | 순서·시간·방법이 번호로 정리됐나 | | |
| 대안 비교 | 다른 선택지와 고르지 않은 이유가 있나 | | |
| 실제 결과 | 좋았던 점·아쉬운 점이 내 경험으로 적혔나 | | |
| 맥락에 맞는 사진·영상 | 직접 찍은 사진 3장 이상이 해당 단계 옆에 있나 | | |
| 직접 경험 · 진정성 | 지어낸 경험이나 남의 사진이 없나, 빈칸이 남았나 | | |
| 일관된 주제 | 제목의 검색어에서 벗어난 내용이 없나 | | |
| 최신성 | 바뀌는 정보에 확인 날짜가 붙었나 | | |
| 제목 | `검색어 + 누구` 형식이고 과장 표현이 없나 | | |

결과 표시: ✅ 충족 / ⚠️ 일부 / ❌ 없음
